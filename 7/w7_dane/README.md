# Dane do Wykładu 7

Uruchamiaj notebook z katalogu `7/`, aby ścieżka `w7_dane/` wskazywała ten katalog.
Plik `przyklad.txt` zawiera trzy małe liczby do podstawowego odczytu; pozostaw go jako wzorzec.

Programy tworzą ponownie lub nadpisują wyłącznie te pliki ćwiczeniowe:

- `w7_demo_zapis.txt` — pierwszy zapis trzech liczb;
- `w7_demo_dopisywanie.txt` — zapis w trybie `w`, potem dopisanie w `a`;
- `w7_demo_wejscie.txt` — dane przygotowane przez komórkę W7.9;
- `w7_demo_wynik.txt` — uporządkowany wynik programu W7.9.

Nazwy `w7_demo_*.txt` są zarezerwowane na odtwarzalne ćwiczenia. Nie przechowuj w nich
ważnych danych. `w7_demo_proba.txt` może być Twoją kopią do prób z błędnym wejściem.
Po nieudanym przetwarzaniu poprzedni plik wynikowy może nadal istnieć — sprawdź status
i komunikat programu. Komórka przygotowująca dane przywraca wzorcowe wejście.
